# Pool Type + Material Guide for US-1 Pools

Purpose: keep site copy, captions, gallery filters, and client photo placement from mixing pool **placement** with pool **construction material**.

## The clean taxonomy

### 1. Placement / install category

- **Above-ground**: Pool sits above grade with visible exterior wall/uprights/top rail. Most use a replaceable vinyl liner inside.
- **In-ground**: Pool is installed below grade. The material/construction type still needs to be named separately.
- **Hot tub / spa / swim spa**: Separate product category from swimming pools.

### 2. In-ground construction material

- **Fiberglass shell**: One-piece factory-made shell, usually gelcoat surface over fiberglass/resin layers. Installed by excavating, setting/leveling the shell, backfilling, plumbing, and deck work. Built-in steps, benches, tanning ledges, and swim zones are molded into the shell.
- **Vinyl liner pool**: Steel, polymer, or similar wall system with a shaped bottom, then a replaceable vinyl membrane/liner forms the waterproof interior surface. Liners may show printed patterns, tile-border prints, seams, or a bead track at the coping.
- **Concrete / gunite / shotcrete**: Rebar and concrete shell built on site, then finished with plaster, pebble, tile, or similar. Highly customizable but not currently a primary US-1 Pools offer in this site copy.

### 3. Above-ground material language

- **Steel**: Steel wall/frame components; strong but rust/corrosion risk matters.
- **Resin**: Hard plastic frame/top-rail/upright components; marketed for corrosion resistance. Resin is not the same thing as fiberglass.
- **Hybrid**: Combination of steel wall/structure with resin components.
- **Vinyl liner**: The interior liner material for above-ground pools. Do not label an above-ground pool as “fiberglass” unless the actual shell is fiberglass.

## Visual ID cheat sheet

| If the photo shows... | Call it... | Avoid calling it... |
| --- | --- | --- |
| One-piece molded shell, integrated stairs/benches/ledges, smooth gelcoat color | Fiberglass in-ground pool/shell | Vinyl liner pool |
| Printed blue liner pattern, tile-border print, seams, wrinkles, liner bead/track, or a liner being stretched/changed | Vinyl liner pool or liner replacement | Fiberglass shell |
| Steel/polymer panel walls before liner is installed | Vinyl-liner in-ground construction | Fiberglass |
| Exposed round/oval/rectangular above-ground wall and uprights | Above-ground pool | In-ground fiberglass |
| Rebar/concrete shell, plaster/pebble/tile finish, waterline tile | Concrete/gunite pool | Fiberglass or vinyl liner |
| Not enough evidence | In-ground pool project / pool installation | Any material-specific claim |

## Site copy rules

1. **Never use “in-ground” as if it means fiberglass.** In-ground is placement; fiberglass/vinyl/concrete are materials.
2. **Never put a known liner photo under a fiberglass brand block.** The client specifically flagged `customer-pool-sunset.webp` as liner.
3. **Use `Pools by Genesis` only when the surrounding copy makes clear it is a fiberglass shell brand.** Use `Genesis` by itself only in the above-ground model context, where it appears with Nakoma/Discovery.
4. **Use process photos carefully.** A liner-change photo can be useful on the liner page, but should be captioned as a replacement/process image, not a polished new-build glamour shot.
5. **If client verification is pending, choose neutral language.** “In-ground pool project” is safer than “fiberglass pool” or “vinyl liner pool.”

## Sources checked

- Latham: fiberglass shells are factory-built from molds; vinyl liners are placed over steel or polymer frames and eventually need replacement. https://www.lathampool.com/blog/research/the-difference-between-fiberglass-and-vinyl-pools/
- SwimmingPool.com: the main in-ground categories are concrete/gunite, vinyl, and fiberglass, each with different customization, cost, and upkeep profiles. https://www.swimmingpool.com/build-a-pool/pool-types/inground-pools/concrete-vinyl-fiberglass/
- River Pools: concrete uses rebar/concrete plus plaster/pebble/tile finish; vinyl liner pools use steel/polymer walls plus a vinyl surface; fiberglass uses factory-made fiberglass/resin/gelcoat shells. https://www.riverpoolsandspas.com/blog/inground-pool-comparison-infographic-vinyl-vs-concrete-vs-fiberglass-pool
- Polaris/Fluidra: above-ground pools vary by frame/wall material, and above-ground liners are vinyl with overlap, beaded, and unibead types. https://www.polarispool.com/en/support/troubleshooting-faqs/buying-guides/types-of-above-ground-pools
- GLI: in-ground liners are custom-made, available in 27/20 mil virgin vinyl, and use a bonding process for seams. https://www.glipoolproducts.com/inground-vinyl-liners/signature-series/
- Pools by Genesis: Genesis positions these as fiberglass in-ground pools with model/color choices. https://poolsbygenesis.com/
- Imagine Fiberglass: fiberglass designs include molded-in ledges, benches, swim lanes, and gelcoat color options. https://imaginefiberglasspools.com/designs/
